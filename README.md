# testtproject

A basic portfolio web app built with plain HTML, CSS, and JavaScript.

## Features

- Responsive design
- Sticky navigation with smooth scrolling
- Hero section
- About section with skills
- Projects grid
- Contact form with client-side handling
- Auto-updating footer year

## Files

- `index.html` — page structure
- `styles.css` — styling and responsive layout
- `script.js` — interactivity (smooth scroll, contact form, dynamic year)

## Deployment

Deployed to Cloudflare Pages at https://testtproject.pages.dev
